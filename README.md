# Study Planner

Semester project for **Software Development Methodologies** (L1, Group 3).

## Product Goal
A web application where university students enter their exam dates and
the system generates an automatic day-by-day study plan with countdown
and warnings.

## Tech Stack
- Backend: Spring Boot (Java 17+), REST API
- Storage: H2 (file-based)
- Frontend: plain HTML + JavaScript (fetch)
- CI: GitHub Actions (build + test)

## How to Run
1. `git clone https://github.com/Katan21/study-planner`
2. `mvn spring-boot:run`
3. Open http://localhost:8080
